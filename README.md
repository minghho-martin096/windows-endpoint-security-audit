# windows-endpoint-security-audit
Windows endpoint security auditing tool for Cybersecurity Challenge Studio, this is my project with Jordan

The Windows Endpoint Security Audit is a lightweight cybersecurity tool designed to assess selected Windows security settings against a predefined security baseline. It identifies insecure or missing configurations, assigns severity levels, and provides clear remediation recommendations to help users improve their system's security posture.
